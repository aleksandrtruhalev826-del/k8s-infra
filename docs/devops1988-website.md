# devops1988.website

Демонстрационный интернет-магазин (Online Boutique) в Kubernetes.

- **URL:** https://devops1988.website/
- **Кластер:** 4 ноды, 66 pod (50 Running), Kubernetes v1.32.13
- **Backend:** Go-микросервисы
- **Proxy:** NGINX, Ingress `shop.devops1988.website`
- **Данные:** PostgreSQL, Redis, Kafka
- **Стек:** Prometheus, Grafana, Argo CD, Vault
